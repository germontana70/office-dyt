# Soberanía de IA Lograda

## Resumen del Proyecto

El proyecto local se centra en un sistema integral para la gestión educativa, con una estructura robusta y modular. Los archivos principales incluyen:

### Directorios Principales:
1. **src**: Contiene la mayoría de los componentes y lógica del sistema:
   - `app`: Componentes principales de la interfaz de usuario.
   - `core`: Dominio y casos de uso centrales.
   - `modules`: Módulos específicos como auditoría, configuración y matrículas.
   - `components`: Componentes reutilizables.

2. **public**: Archivos estáticos como logos y assets.

3. **supabase**: Configuraciones y migraciones para la base de datos.

4. **infra**: Servicios y repositorios.

5. **scripts y configuración**:
   - `package.json`: Dependencias principales.
   - `tsconfig.json`: Configuración TypeScript.
   - `next.config.js`: Configuración del servidor.

### Funcionalidades Principales:
- Auditoría financiera y operativa.
- Gestión de estudiantes y matrículas.
- Integración con Google Calendar.
- Sistema de precios y configuraciones globales.
- Herramientas de sincronización y migración.

El proyecto utiliza tecnologías como Next.js, TypeScript, Docker y Supabase, demostrando una arquitectura moderna y robusta.
